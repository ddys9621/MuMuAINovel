# 如何创建新项目

简洁的分步操作列表，用于在 MuMuAINovel 中创建新项目。

## 方式一：使用项目向导（推荐）

1. **打开项目列表页**：登录后进入首页（`/` 或 `/projects`）
2. **点击"创建项目"按钮**：在欢迎头部或空状态页面点击"创建项目"按钮
3. **填写项目信息**：在弹出的 Modal 中填写项目名称、类型、简介等基本信息
4. **选择 MCP 插件**（可选）：选择需要使用的 MCP 插件（如搜索、知识库等）
5. **提交并生成**：点击"开始生成"，系统将使用 AI 生成项目的初始设定
6. **等待生成完成**：进度条显示生成进度，完成后可选择进入项目或返回列表

**重要**：生成过程中无法关闭 Modal，请耐心等待。

## 方式二：使用灵感模式

1. **打开项目列表页**：登录后进入首页
2. **点击"💡 灵感模式"按钮**：在欢迎头部点击"灵感模式"按钮
3. **与 AI 对话**：在右侧抽屉中与 AI 对话，描述你的创作想法
4. **选择建议选项**：AI 会提供多个选项，点击选择你喜欢的方向
5. **逐步细化**：通过多轮对话，逐步细化项目设定
6. **生成项目**：确认后，系统将生成完整的项目设定
7. **进入项目**：生成完成后，可直接进入项目开始创作

**提示**：灵感模式适合没有明确想法的创作者，通过对话激发灵感。

## 验证

- 创建成功后，项目列表中会显示新项目卡片
- 点击项目卡片可进入项目详情页
- 项目详情页包含世界观、角色、剧情、章节等模块
